# Z-Music

Z-Music adalah YouTube Music client untuk Android. Gratis, tanpa iklan, dan open source.

## Fitur
- Stream musik tanpa iklan
- Background playback
- Download & cache lagu untuk offline
- Live lyrics (karaoke style)
- Material You design
- Tidak perlu login Google

## Download
Download APK terbaru di [Releases](../../releases/latest)

## Build dari Source
1. Clone repo ini
2. Buka di Android Studio
3. Build → Generate Signed APK
